# Color palette suggestions

Change the `theme` field at the top of `selfOS.md`, then run `./build.sh`.

## 1. Terracotta — recommended default

```yaml
theme: terracotta
```

- Background: `#FAF8F3`
- Text: `#24211D`
- Primary accent: `#A94F35`
- Secondary accent: `#8A5F1F`
- Surface: `#FFFDF9`

Warm, personal, and close to the current reference homepage. It works especially
well with the orange profile image and feels less institutional than a typical
blue academic site.

## 2. Ink

```yaml
theme: ink
```

- Background: `#F5F7F8`
- Text: `#1F2A35`
- Primary accent: `#315F7D`
- Secondary accent: `#855D37`
- Surface: `#FBFDFF`

Calm, technical, and conservative. This is the safest option if the homepage is
mainly used for academic applications, paper links, and professional outreach.

## 3. Sage

```yaml
theme: sage
```

- Background: `#F5F7F2`
- Text: `#223029`
- Primary accent: `#3F6B57`
- Secondary accent: `#9D5535`
- Surface: `#FBFDF9`

Quiet and distinctive without becoming playful. It pairs well with spatial,
world-model, simulation, and environment-oriented research.

## 4. Plum

```yaml
theme: plum
```

- Background: `#FAF6F7`
- Text: `#2B2228`
- Primary accent: `#7A4058`
- Secondary accent: `#9D513D`
- Surface: `#FFFDFD`

More editorial and memorable. It gives the site a research-portfolio character
while remaining restrained enough for an academic homepage.

## Recommendation

Keep `terracotta` if you want continuity with the current visual identity. Use
`ink` for the most formal presentation, `sage` for the best thematic match to
spatial intelligence, or `plum` when recognizability matters most.

All body text and accent colors in these presets meet WCAG AA contrast for
normal-sized text against their page backgrounds.
